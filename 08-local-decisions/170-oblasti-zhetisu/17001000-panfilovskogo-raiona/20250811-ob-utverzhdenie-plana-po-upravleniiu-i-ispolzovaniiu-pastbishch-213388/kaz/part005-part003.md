# 1. Жер учаскесіне құқық белгілейтін құжаттар негізінде жер санаттары, жер учаскелерінің меншік иелері және жер пайдаланушылар бөлісінде Панфилов ауданының аумағында жайылымдардың орналасу схемасы (картасы)

# 2. Жеке ауладағы ауылшаруашылғы жануарларын жаю бойынша халықтың мұқтажына арналған жайылымдар,оның ішінде көпшілік пайдаланатын жайылымдар белгіленген схеманы(картасы)

# 3. Жайылым айналымдарының ұсынылатын схемасы (картасы)

# 4. Ауылшаруашылығы жануарларын айдап өтуге арналған сервитуттар,мал айдайтын жолдар мен өзге де жайылымдық инфрақұрылым обьектілері,сондай-ақ мал қорымыдары(биометриалық шұңқырлар)белгіленген схемасы (картасы)

# 5. Жайылым пайдаланушыларға жер пайдалануға берілуі мүмкін жайылымдар белгіленген схемасы схемасы(картасы)

# 6. Жеке ауладағы ауылшаруашылғы малын жаю бойынша халықтың мұқтажын қанағаттандыру мақсатында резервке қойылуға тиісті жайылымдар белгіленген схемасы(картасы)

# 7. Су тұтыну нормасына сәйкес жасалған су көздеріне (көлдерге, өзендерге, тоғандарға, апандарға, суару немесе суландыру каналдарына, құбырлы немесе шахталы құдықтарға) қол жеткізу схемасы

# 8. Ауылшаруашылығы жануарларының мал басын шалғайдағы жайылымдарға орналастыру схемасы(картасы)
