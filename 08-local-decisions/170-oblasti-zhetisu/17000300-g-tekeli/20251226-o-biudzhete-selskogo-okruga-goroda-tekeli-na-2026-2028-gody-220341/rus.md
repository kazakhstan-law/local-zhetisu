# О бюджете сельского округа города Текели на 2026-2028 годы

> *Сноска. Вводится в действие с 01.01.2026 в соответствии с пунктом 2 настоящего решения.*

РЕШИЛ:

1. Утвердить бюджет Рудничного сельского округа на 2026-2028 годы согласно приложениям 1, 2 и 3 к настоящему решению соответственно, в том числе на 2026 год в следующих объемах:

   1) доходы 57 200 тыс. тенге, в том числе:

      налоговые поступления 8 500 тыс. тенге;

      неналоговые поступления 0 тыс.тенге;

      поступления от продажи основного капитала 0 тыс.тенге;

      поступления трансфертов 48 700 тыс.тенге;

   2) затраты 57 200 тыс. тенге;

   3) чистое бюджетное кредитование 0 тыс.тенге, в том числе:

      бюджетные кредиты 0 тыс.тенге;

      погашение бюджетных кредитов 0 тыс.тенге;

   4) сальдо по операциям с финансовыми активами 0 тыс.тенге, в том числе:

      приобретение финансовых активов 0 тыс.тенге;

      поступления от продажи финансовых активов государства 0 тыс.тенге;

   5) дефицит (профицит) бюджета (-) 0 тыс.тенге;

   6) Ненефтяной дефицит (профицит) бюджета-0 тыс.тенге

   7) финансирование дефицита (использование профицита) бюджета 0 тыс.тенге, в том числе:

      поступление займов 0 тыс.тенге;

      погашение займов 0 тыс.тенге;

      используемые остатки бюджетных средств 0 тыс.тенге.

2. Настоящее решение вводится в действие с 1 января 2026 года.

   **Временно исполняющий полномочия председателя городского маслихата**

   **______________ М. Ботантаев**
