# Текелі қаласының ауылдық округінің 2025-2027 жылдарға арналған бюджеті туралы

> *Ескерту. 01.01.2025 бастап қолданысқа енгізіледі - осы шешімнің 2-тармағымен.*

ШЕШІМ ҚАБЫЛДАДЫ:

1. 2025-2027 жылдарға арналған Рудничный ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2025 жылға келесі көлемдерде бекітілсін:

   1) кірістер 47 544 мың теңге, оның ішінде:

      салықтық түсімдер 5 291 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 42 253 мың теңге;

   2) шығындар 47 544 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге, оның ішінде:

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге, оның ішінде:

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражаттарының пайдаланылатын қалдықтары 0 теңге.

2. Осы шешім 2025 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі.

   **Текелі қалалық мәслихатының төрағасы**

   **Б. Тугулбаев**

> *Текелі қалалық мәслихатының 2024 жылғы 27 желтоқсандағы № 27-125 шешімімен бекітілген 1-қосымша*
