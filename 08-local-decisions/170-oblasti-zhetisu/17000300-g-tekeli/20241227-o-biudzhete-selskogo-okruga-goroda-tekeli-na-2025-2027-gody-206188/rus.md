# О бюджете сельского округа города Текели на 2025-2027 годы

> *Сноска. Вводится в действие с 01.01.2025 в соответствии с пунктом 2 настоящего решения.*

РЕШИЛ:

1. Утвердить бюджет Рудничного сельского округа на 2025-2027 годы согласно приложениям 1, 2 и 3 к настоящему решению соответственно, в том числе на 2025 год в следующих объемах:

   1) доходы 47 544 тысяч тенге, в том числе:

      налоговые поступления 5 291 тысяч тенге;

      неналоговые поступления 0 тенге;

      поступления от продажи основного капитала 0 тенге;

      поступления трансфертов 42 253 тысяч тенге;

   2) затраты 47 544 тысяч тенге;

   3) чистое бюджетное кредитование 0 тенге, в том числе:

      бюджетные кредиты 0 тенге;

      погашение бюджетных кредитов 0 тенге;

   4) сальдо по операциям с финансовыми активами 0 тенге, в том числе:

      приобретение финансовых активов 0 тенге;

      поступления от продажи финансовых активов государства 0 тенге;

   5) дефицит (профицит) бюджета (-) 0 тенге;

   6) финансирование дефицита (использование профицита) бюджета 0 тенге, в том числе:

      поступление займов 0 тенге;

      погашение займов 0 тенге;

      используемые остатки бюджетных средств 0 тенге.

2. Настоящее решение вводится в действие с 1 января 2025 года.

   **Председатель Текелийского городского маслихата**

   **Б. Тугулбаев**

> *Приложение 1 утвержденное решением Текелийского городского маслихата от 27 декабря 2024 года № 27-125*
