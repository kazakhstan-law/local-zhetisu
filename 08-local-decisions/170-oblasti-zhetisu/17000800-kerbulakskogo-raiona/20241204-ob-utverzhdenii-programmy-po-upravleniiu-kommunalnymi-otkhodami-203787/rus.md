# Об утверждении программы по управлению коммунальными отходами в Кербулакском районе области Жетісу на 2024-2029 годы

В соответствии с подпунктом 1) пункта 3 статьи 365 Экологического кодекса Республики Казахстан, Кербулакский районный маслихат РЕШИЛ:

1. Утвердить программу по управлению коммунальными отходами в Кербулакском районе области Жетісу на 2024-2029 годы согласно приложению к настоящему решению.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

   **Председатель Кербулакского районного маслихата**

   **К. Бекиев**

> *Приложение к решению Кербулакского районного маслихата от 4 декабря 2024 года № 20-165*

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](rus/part001.md) | по управлению коммунальными отходами в Кербулакском районе области Жетiсу на 2024-2029 годы |
| [`part004`](rus/part004.md) | `!` Общая справка по Кербулакскому району |
| [`part004-t001`](rus/part004-t001.md) | таблица 1 |
| [`part004-part002`](rus/part004-part002.md) | part004-part002 |
| [`part004-t002`](rus/part004-t002.md) | таблица 2 |
| [`part004-part004`](rus/part004-part004.md) | part004-part004 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
