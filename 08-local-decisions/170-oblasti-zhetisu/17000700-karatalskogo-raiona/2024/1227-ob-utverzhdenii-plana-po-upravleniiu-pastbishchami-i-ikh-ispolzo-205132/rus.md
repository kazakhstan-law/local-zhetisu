# Об утверждении плана по управлению пастбищами и их использованию по Каратальскому району на 2025-2029 годы.

В соответствии с подпунктом 1) статьи 8 Закона Республики Казахстан «О пастбищах» Каратальский районный маслихат РЕШИЛ:

<a id="p1"></a>

1. Утвердить план по управлению пастбищами и их использованию по Каратальскому району на 2025-2029 годы согласно приложению к настоящему решению.

<a id="p2"></a>

2. Контроль за исполнением настоящего решения возложить на курирующего заместителя акима района.

<a id="p3"></a>

3. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

   **Председатель маслихата**

   **Акимжанов М.**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](rus/part001.md) | Об утверждении плана по управлению пастбищами и их использованию по Каратальскому району на 2025-2029 годы. |
| [`part001-part002`](rus/part001-part002.md) | `!` part001-part002 |
| [`part002`](rus/part002.md) | Пояснение по заполнению формы, предназначенной для сбора административных данных "Численность поголовья сельскохозяйственных животных из базы данных идентификации сельскохозяйственных животных" (БДИСЖ-1) |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
